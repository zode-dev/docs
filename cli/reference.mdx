A `<sandbox>` is a sandbox's name or `sbx_` id. Where `--env ENV` appears, ENV is an environment name or `env_` id and defaults to `default`. Commands that read a secret value (`zode secret set`, `zode ai-key add`, `zode alert channel add` without `--url`, `zode otel set --header`) read it from stdin, or ask for it without echo at a terminal. `ZODE_TOKEN` and `ZODE_API` override the saved sign-in ([Environment variables](/cli/overview#environment-variables)).

| `zode rm <sandbox>` | | Delete, with its disk. |

| `zode sandbox scaling <sandbox>` | | Size changes, newest first. [Scaling history](/cli/sandboxes#scaling-history) |
